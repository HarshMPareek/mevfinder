# Learn articles

Every Markdown file here is an article on [mevfinder.com/learn](https://mevfinder.com/learn). Adding one is a pull request:

```markdown
---
title: What a backrun is
date: 2026-11-20
summary: One sentence shown in the article list.
---

The article, in Markdown.
```

- File name = URL slug: lower case letters, digits and hyphens (`what-a-backrun-is.md` -> `/learn/what-a-backrun-is`).
- Newest `date` first. Numbers in an article must come from the site's own data, never estimates.
- Files whose name is not a valid slug (like this README) are not served.
