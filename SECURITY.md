# Security

Please report a vulnerability privately, not in a public issue: use **Report a vulnerability** under this repository's
*Security* tab, or write to [info@mevfinder.com](mailto:info@mevfinder.com). We answer within a few days and credit
reporters who want it.

In scope: this code and mevfinder.com (the website and its JSON API). Out of scope: rate-limit and denial-of-service
testing against the live site, and the blockchains or explorers it reads.
